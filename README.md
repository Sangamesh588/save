# MediaDownloader Pro 🚀

A fast, clean, universal video and music downloader with in-browser playback, precision clip trimming, automated ID3 album cover art tagging, subtitle extraction, and Progressive Web App (PWA) support.

---

## ✨ Features

- 🎥 **Universal Video Downloads**:
  - Download in **4K (2160p)**, **2K (1440p)**, **Full HD (1080p)**, **HD (720p)**, **480p**, and **360p**.
  - Encoded with high-compatibility **H.264 video + AAC audio** in `.mp4` format so videos play seamlessly on any computer, phone, or browser without missing codecs.
- 🎬 **Watch In-Browser Player**:
  - Watch videos or listen to songs directly in the on-screen player before and after downloading.
  - Save file to your computer with a single click.
- ✂️ **Precision Clip Cutter / Trimmer**:
  - Enter a **Start Time** (e.g. `00:15`) and **End Time** (e.g. `00:45`), or use 1-click presets (`First 15s`, `First 30s`, `First 1m`).
  - Cut hooks, highlights, memes, or WhatsApp status clips in seconds without wasting bandwidth.
- 🏷️ **Automatic ID3 Album Art & Artist Tagging**:
  - When downloading MP3 songs, the video thumbnail is automatically embedded as the official **Album Cover Art (ID3v2 APIC)**.
  - Artist and track title metadata are written into the file so they show up properly in Apple Music, Spotify local files, and car stereos.
- 🖼️ **HD Thumbnail Downloader**:
  - Download original high-resolution (1080p JPG) thumbnail images with one click.
- 📝 **Subtitle & Transcript Downloader**:
  - Download subtitles in `.srt` (for video editing) or clean plain text `.txt` (transcripts for study, notes, or translation).
- 📱 **Installable PWA (Progressive Web App)**:
  - Tap **"Install App"** to install it directly on your Windows desktop, Android phone, or iPhone Home Screen like a native app.
- 🎨 **Clean, Human-Designed UI**:
  - Simple, elegant dark slate styling without neon purple AI clutter. Fast, focused, and responsive.

## 🚀 Running the Application

Double-click **`run.bat`** or run:
```bash
python app.py
```
Visit **[http://localhost:5000](http://localhost:5000)** in your browser.
